# Programación en R para Geología y Biología

**Curso de 5 semanas · 20 horas presenciales · clases lunes/miércoles (90 min) y taller viernes (60 min).**

Este es **un único repositorio**: `estudiantes/` contiene el material público en formato Jupyter `.ipynb` (kernel R); `data/` contiene datos comunes **sintéticos**; `docente/` contiene guías, fuentes y soluciones **excluidas por `.gitignore`**. El docente puede trabajar con VS Code y un kernel R local o en Colab.

> **Antes de publicar**, configura el nombre del repositorio: `python scripts/configure_github_repo.py OWNER/REPO`. Los botones usan el nombre provisional `eamontoyaa/EAFIT_herramientas_computacionales_modulo_R` y no funcionarán hasta ejecutar ese comando y subir el contenido a GitHub. Usa rama `main` y repositorio público para apertura directa.

## Reproducibilidad

1. En Colab selecciona un runtime **R** (si aparece Python, cambia el tipo de entorno). Ejecuta `00_prueba_entorno.ipynb` y después cada notebook **de arriba a abajo**. Los primeros paquetes espaciales pueden tardar en instalarse.
2. Las celdas de preparación buscan `data/` si trabajas localmente; en Colab descargan `data/curso_R_data.zip` desde el repositorio configurado y disponen de un respaldo embebido. Requiere internet en la primera preparación y acceso a CRAN para paquetes no instalados.
3. En VS Code abre la carpeta raíz y selecciona un kernel R de Jupyter; no uses rutas absolutas ni `setwd()`.
